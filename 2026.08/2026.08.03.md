## 2 HackerRank 문제 풀이

### [Non-Divisible Subset](https://www.hackerrank.com/challenges/non-divisible-subset/problem?isFullScreen=true)

```cpp
int nonDivisibleSubset(int k, vector<int> s) {
    vector<int> count(k, 0);
    int answer = 0;
    for(int i=0; i<s.size(); i++)
        ++count[s[i] % k];
        
    if(count[0] > 0) answer++;
    
    for(int i=1; i<=k/2; i++){
        if(i*2 == k && count[i] > 0) answer++;
        else answer += max(count[i], count[k-i]);
    }
        
    return answer;
}
```

* **수학**, **그리디** 문제
* **나머지를 기준**으로 수를 카운팅
* 나머지가 `i`인 수, 나머지가 `k-i`인 수를 둘 다 고르면 **두 수의 합은 `k`로 나누어 떨어지므로** 둘 중 큰 것만 선택
* 나머지가 `0`인 경우, `k/2`인 경우는 **동일한 나머지를 갖는 수를 고르면 나누어 떨어지므로** 최대 `1`개

### [완주하지 못한 선수](https://school.programmers.co.kr/learn/courses/30/lessons/42576)

```cpp
#include <string>
#include <vector>
#include <unordered_map>

using namespace std;

string solution(vector<string> participant, vector<string> completion) {
    unordered_map<string, int> map;
    for(int i=0; i<participant.size(); i++)
        map[participant[i]]++;
    for(int i=0; i<completion.size(); i++)
        map[completion[i]]--;
    for(const auto& [name, count] : map)
        if(count != 0) return name;
    return "";
 }
```

* **해시맵** 문제
* 카운트가 `0`이 아닌 경우 완주하지 못한 것

### [[1차] 다트 게임](https://school.programmers.co.kr/learn/courses/30/lessons/17682)

```cpp
#include <string>
#include <vector>
#include <cmath>

using namespace std;

int solution(string dartResult) {
    int answer = 0;
    vector<int> score;
    
    string num = "";
    for(int i=0; i<dartResult.length(); i++){
        if(isdigit(dartResult[i])) num += dartResult[i];
        else if(isalpha(dartResult[i])){
            int s = stoi(num);
            num = "";
            if(dartResult[i] == 'S') score.push_back(pow(s, 1));
            else if(dartResult[i] == 'D') score.push_back(pow(s, 2));
            else score.push_back(pow(s, 3));
        }
        else if(dartResult[i] == '*'){
            score.back() *= 2;
            if (score.size() > 1) 
                score[score.size() - 2] *= 2;
        }
            
        else score.back() = -score.back();
    }
    for(int i=0; i<3; i++) answer += score[i];
    return answer;
}
```

* **문자열 파싱**, **구현** 문제
* `*`연산 시 2번째 기회 이후면 이전 것까지 곱해줌

### [[PCCE 기출문제] 9번 / 이웃한 칸](https://school.programmers.co.kr/learn/courses/30/lessons/250125)

```cpp
#include <string>
#include <vector>

using namespace std;

int solution(vector<vector<string>> board, int h, int w) {
    int answer = 0;
    string color = board[h][w];
    int dy[4] = {-1, 1, 0, 0};
    int dx[4] = {0, 0, -1, 1};
    for(int i=0; i<4; i++){
        int ny = h + dy[i];
        int nx = w + dx[i];
        if(ny<0 || ny>= board.size() || nx<0 || nx>=board[0].size()) continue;
        if(board[ny][nx] == color) answer++;
    }
    return answer;
}
```

* **시뮬레이션** 문제
* 상하좌우 칸 비교하면 되는 간단한 문제
* **BFS**, **DFS**와 유사하게 작성

### [실패율](https://school.programmers.co.kr/learn/courses/30/lessons/42889)

```cpp
#include <string>
#include <vector>
#include <algorithm>
#include <unordered_map>

using namespace std;

vector<int> solution(int N, vector<int> stages) {
    vector<int> answer;
    unordered_map<int, double> rate;
    vector<int> fail(N+2, 0);
    sort(stages.rbegin(), stages.rend());
    
    for(int i=1; i<=N; i++) rate[i] = 0;
    for(int i=0; i<stages.size(); i++){
        if(stages[i] > N) continue;
        fail[stages[i]]++;
        rate[stages[i]] = fail[stages[i]] / (i+1.0);
    }
    
    vector<pair<int, double>> sorted(rate.begin(), rate.end());
    sort(sorted.begin(), sorted.end(), [](const pair<int, double>& A, const pair<int, double>& B){
        if(A.second != B.second) return A.second > B.second;
        else return A.first < B.first;
    });
    
    for(int i=0; i<sorted.size(); i++)
        answer.push_back(sorted[i].first);
    
    return answer;
}
```

* **정렬**, **구현** 문제
* 해당 스테이지에서 실패한 사람의 수는 `stages`에서 카운트한 수
* `stages`를 **역순으로 정렬**하면, 인덱스는 해당 **스테이지에 도달한 사람의 수를 의미**함
* 두 값을 통해 실패율 계산
* 이후 문제의 정렬 기준대로 정렬

### [소수 찾기](https://school.programmers.co.kr/learn/courses/30/lessons/12921)

```cpp
#include <string>
#include <vector>

using namespace std;

int solution(int n) {
    int answer = 0;
    vector<int> prime(n+1, 1);

    for(int i=2; i<prime.size(); i++){
        if(prime[i] == 0) continue;
        for(int j=i*i; j<prime.size(); j+=i)
            prime[j] = 0;
    }
        
    for(int i=2; i<prime.size(); i++)
        answer += prime[i];
    
    return answer;
}
```

* **수학** 문제
* **에라토스테네스의 체**를 활용해 풀이

### [추억 점수](https://school.programmers.co.kr/learn/courses/30/lessons/176963)

```cpp
#include <string>
#include <vector>
#include <unordered_map>

using namespace std;

vector<int> solution(vector<string> name, vector<int> yearning, vector<vector<string>> photo) {
    vector<int> answer(photo.size(), 0);
    unordered_map<string, int> map;
    for(int i=0; i<name.size(); i++)
        map[name[i]] = yearning[i];
    
    for(int i=0; i<photo.size(); i++)
        for(const string& n : photo[i])
            answer[i] += map[n];
        
    return answer;
}
```

* **해시맵** 문제
* 각 이름의 점수를 저장

### [문자열 내 p와 y의 개수](https://school.programmers.co.kr/learn/courses/30/lessons/12916)

```cpp
#include <string>
#include <iostream>
using namespace std;

bool solution(string s)
{
    int p = 0, y = 0;
    for(int i=0; i<s.length(); i++){
        if(s[i] == 'p' || s[i] == 'P') p++;
        else if(s[i] == 'y' || s[i] == 'Y') y++;
    }

    return p == y;
}
```

* **문자열** 문제
* **대소문자 구분 없이** 카운트를 증가
