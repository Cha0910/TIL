### [Save the Prisoner!](https://www.hackerrank.com/challenges/save-the-prisoner/problem)

```cpp
int saveThePrisoner(int n, int m, int s) {
    int start = s - 1;
    int move = m - 1;
    int answer = (start + move) % n + 1;
    return answer;
}
```

* **수학** 문제
* 나머지 연산 문제, 시작이 `1`로 시작하므로 `0`으로 맞춰줌

### [Find the Largest Almost Missing Integer](https://leetcode.com/problems/find-the-largest-almost-missing-integer/description/)

```cpp
#include <unordered_map>

class Solution {
public:
    int largestInteger(vector<int>& nums, int k) {
        int answer = -1;
        if(k == nums.size()) {
            for(int i=0; i<nums.size(); i++) answer = max(answer, nums[i]);
            return answer;
        }

        unordered_map<int, int> count;
        for(int i=0; i<nums.size(); i++) count[nums[i]]++;
        if(k == 1) {
            for(auto& [n, c] : count) if(c == 1) answer = max(answer, n);
            return answer;
        }

        if(count[nums[0]] == 1) answer = max(answer, nums[0]);
        if(count[nums.back()] == 1) answer = max(answer, nums.back());

        return answer;
    }
};
```

* **구현**, **수학** 문제
* `k = nums.size()`인 경우, `k = 1`인 경우,  `1 < k < nums.size()`인 경우 세 가지로 나눌 수 있음
* `k = nums.size()`인 경우는 모든 수가 조건을 만족하므로 최댓값 반환
* `k = 1`인 경우는 하나만 있는 수 중 최댓값을 반환
* 그 외의 경우, **사이에 있는 수는 반드시 2개 이상의 부분 집합**에 나올 수 밖에 없음
* 따라서 **양 끝에 있는 수 중 큰 값**이 정답

### [Add Two Numbers](https://leetcode.com/problems/add-two-numbers/description/)

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */

class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        vector<int> vecA, vecB;
        int a = 0, b = 0;
        while(l1 != nullptr){
            vecA.push_back(l1->val);
            l1 = l1->next;
        }
        while(l2 != nullptr){
            vecB.push_back(l2->val);
            l2 = l2->next;
        }

        vector<int> vec(max(vecA.size(), vecB.size()), 0);
        for(int i=0; i<vec.size(); i++){
            if(i<vecA.size()) vec[i] += vecA[i];
            if(i<vecB.size()) vec[i] += vecB[i];
            if(vec[i] >= 10){
                if(i+1 < vec.size()) vec[i+1]++;
                else vec.push_back(1);
                vec[i] %= 10;
            }
        }
        
        ListNode* l3 = new ListNode(vec.back());  
        for(int i=vec.size()-2; i>=0; i--){
            ListNode* temp = new ListNode(vec[i], l3);
            l3 = temp;
        }
        return l3;
    }
};
```

* **구현**, **연결 리스트**, **큰 수 더하기** 문제
* 주어진 연결 리스트를 순회하여 새로운 연결 리스트를 만드는 문제
* 자릿수가 클 경우 **오버플로우**가 발생하므로, **올림 처리**를 통해 계산
