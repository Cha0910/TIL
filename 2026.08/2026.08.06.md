### [야근 지수](https://school.programmers.co.kr/learn/courses/30/lessons/12927)

```cpp
#include <string>
#include <vector>
#include <queue>
#include <cmath>

using namespace std;

long long solution(int n, vector<int> works) {
    long long answer = 0;
    priority_queue<long long> pq;
    for(int i=0; i<works.size(); i++) pq.push(works[i]);
    
    while(n>0 && !pq.empty()){
        long long work = pq.top();
        pq.pop();
        --n;
        if(--work == 0) continue;
        pq.push(work);
    }
    
    while(!pq.empty()){
        long long work = pq.top();
        pq.pop();
        answer += work * work;
    }
    
    return answer;
}
```

* **그리디**, **우선순위 큐** 문제
* 야근 지수를 최소화하기 위해선 **남은 일 중 가장 높은 작업량**을 가진 일을 하는 것이 최선
* 남은 일을 우선순위 큐로 관리해 항상 가장 큰 일만 꺼냄
* `n`의 크기를 **N**, `works`의 길이를 **M**이라 하면 시간 복잡도는 `O(MLogM + NLogM)`
* `n`의 크기가 최대 `1,000,000`, `works`의 길이가 최대 `20,000`이므로 충분히 해결 가능

### [거스름돈](https://school.programmers.co.kr/learn/courses/30/lessons/12907)

```cpp
#include <string>
#include <vector>

using namespace std;

int solution(int n, vector<int> money) {
    vector<int> dp(n+1, 0);
    dp[0] = 1;
    
    for(int i=0; i<money.size(); i++){
        for(int j=0; j<dp.size(); j++){
            if(j-money[i] < 0) continue;
            dp[j] += dp[j-money[i]];
            dp[j] %= 1000000007;
        }
    }
    return dp[n];
}
```

* **DP** 문제
* `0`원을 만드는 방법은 아무 동전도 쓰지 않는 경우 `1`가지
* 동일한 조합의 동전을 사용하는 경우는 같은 경우로 취급하므로, 동전이 바깥 반복문
